# Yee · Humanist 公开展示

主页沿用个人网站的“研究、构建、记录”叙事，太阳为个人品牌识别；项目保留各自概念，共享暖纸、炭褐与陶土色。

- yee-banner.svg：内置 ImageGen 生成的太阳页眉，包裹暖纸底；文字 alt 提供相同含义。非矢量化。
- humanist.svg：错位框与陶土方点。
- interlude.svg：圆润胖雀与陶土翅膀。
- visual-inspection.svg：取景框、检测点与确认标记。
- schednav.svg：任务队列与有界调度路径。

四个展示标识与对应仓库 docs/assets/brand/mark.svg、网站 public/brand/*.svg 保持逐字节一致。README 正文保持可选择、可访问的真实文字，GitHub 的界面字体沿用平台原生设置。
